# Dust 水印相机

> 纯前端、单文件的照片水印工具：把时间、地址、日期和相机水印条按原图分辨率烧录进照片，并根据画面明暗自动选择水印位置。

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)


**最快开始**：下载仓库，直接双击 `index.html`。无需安装、无需构建、无第三方依赖。

## ✨ 功能

- **四种导入方式**：拖拽照片到预览区、`Ctrl + V` 粘贴、文件选择（支持多选）、调用摄像头实时取景，点击取景画面即可定格拍照。
- **原分辨率导出**：按照片原始尺寸重新绘制水印，输出 JPEG（质量 0.94），可选单张或批量；相机拍照按视频分辨率定格为照片，与导入照片一样编辑和导出。
- **自动选位**：把照片缩到 64×64，统计亮度与梯度，在 6 个锚点中为水印挑选更干净的位置，默认优先保留「底部通栏」构图。
- **自动衬底**：根据区域高光、平均亮度和杂乱度动态叠加暗色渐变，避免白字融进亮部；也可强制开/关。
- **排版自适应**：水印块尺寸随照片短边缩放；文字先缩小字号、再折行，超长地址最多两行并自动省略；时间使用横向压缩模拟窄体字。
- **即时预览**：修改文字、位置、衬底、大小后立即重绘；状态条实时显示实际位置、衬底强度、区域亮度中位数/P90、杂乱度、地址行数。
- **高级微调**：可分别调整整块水印、时间、地址、日期的位移与字号，支持一键复位。
- **参数记忆与一键重置**：水印位置、衬底、大小、微调、地址自动写入 `localStorage`，下次打开自动恢复；A 时间与 C 日期不保存，始终取当前时间、日期和星期。点「一键重置参数」可恢复全部默认值并清空本地记录。
- **本地预设**：把当前参数（位置、衬底、大小、微调、地址）保存为自定义名称的预设，可保存多个、点击切换、同名覆盖或删除；预设同样保存在浏览器本地，重置参数时不会被清除。
- **离线可用**：水印底图以 base64 data URI 内联，`file://` 下打开也不会污染 Canvas，导出不会触发 `SecurityError`。


## 🚀 快速上手

1. **导入照片**：拖拽、粘贴，或点右侧「导入照片」（可多选）；也可以点「使用相机」实时取景，取景框上方会提示“点击画面进行拍照”，点一下画面即定格当前帧：相机关闭，照片加入列表并进入水印编辑。再次使用相机拍照，新照片会追加到列表。
2. **填写水印文字**：A 时间、B 地址、C 日期，输入即时生效；点「按当前时间刷新」会重置时间日期，并重新生成随机码。
3. **调整样式**：选择水印位置（默认底部通栏，可选自动）、底板衬底（默认不加）、水印大小；需要精细控制时展开「高级微调」。
4. **导出**：点「导出当前」输出当前照片；列表中有多张时可用「批量导出」。文件命名形如 `原文件名_水印_20261110_1530.jpg`。
5. **保存预设**：填写预设名称后点「保存预设」；需要切换时在「切换预设」中选择即可套用，同名保存会更新该预设。
6. **查看结果**：预览下方状态条显示原图尺寸、最终位置、衬底百分比、区域亮度与导出后的文件体积。

> 默认地址是示例文本，请在导出前改成实际地址。除 A 时间和 C 日期外，水印参数会自动保存在浏览器本地，下次打开直接沿用。

## 🛠️ 开发说明

- **无构建流程**：直接编辑 `index.html`，刷新浏览器即可。没有 npm 依赖、打包步骤和自动化测试。
- **替换水印底图**：在 PSD 中导出 3024×938 的 PNG，转成 base64 后替换 `STRIP_URI`。必须保持内联 data URI，否则 `file://` 下 Canvas 会被污染，`toBlob` 导出抛 `SecurityError`。
- **调整版式**：文字坐标常量 `L`、块高比例 `BLOCK_FRAC`、边距 `MARGIN_FRAC`、时间横向压缩 `TIME_SQUEEZE` 都按真机截图实测换算，改动后请同时检查横图、竖图、全景图和不同分辨率。
- **调整自动选位**：评分权重、`AUTO_ORDER` 尝试顺序和 `SWITCH_MARGIN` 切换阈值集中在 `decide()`；调高阈值可减少位置切换，调低会更激进地避让杂乱区域。
- **参数持久化**：键名为 `dust-watermark-settings-v1`，只保存 `position`、`scrim`、`size`、`tune`、`addr`，不保存照片、A 时间和 C 日期；读取时会对枚举、数值范围做校验。
- **预设持久化**：键名为 `dust-watermark-presets-v1`，结构为 `[{ name, settings }]`，`settings` 与当前参数同构；应用预设会同时写回当前参数。
- **修改默认文字**：启动函数 `boot()` 中写入默认时间、日期和示例地址；`DEFAULT_ADDR` 控制重置后的地址。
